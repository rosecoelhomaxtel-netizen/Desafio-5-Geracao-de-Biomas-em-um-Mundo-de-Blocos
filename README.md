# ⛏️ Desafio 5: Geração de Biomas em um Mundo de Blocos

Resolução do desafio de lógica de programação da **DIO (Digital Innovation One)**.

## 📝 Descrição
Simula a mineração de blocos com picareta onde cada golpe atinge uma rocha e extrai um mineral:
- `1` ➔ Carvão
- `2` ➔ Ferro
- `3` ➔ Diamante
- `4` ➔ Pedra

## 📥 Entrada
- Quantidade de golpes (número inteiro).

## 📤 Saída
- `[número do golpe]: [nome do mineral]`
